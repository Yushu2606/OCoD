# 首版验收基础桌面角色行为

Windows 和 macOS 首版验收透明浮窗、拖动与缩放、翻转与锁定、置顶与鼠标穿透、点击与闲置动画及台词、基础部件和配音。

Windows 和 macOS 首版提供简体中文、英文、日文和韩文界面。所有中文语言区域（包括繁体中文）统一回退到简体中文。覆盖启动器、安装与更新提示、托盘或菜单栏、角色管理窗口、角色菜单和编辑器。角色名、台词等作者内容按原文保存和交换。

全局守护进程提供 Windows 通知区域图标和 macOS 菜单栏入口。用户可以从该入口打开角色管理窗口，对指定角色关闭鼠标穿透。

首版默认手动启动，设置中可开启登录时启动 OCoD。开启后，由全局守护进程恢复上次仍在桌面的角色。Windows 便携角色库所在位置在登录时不可用，则跳过该库。

首版提供基础角色创作和编辑。作者可以从零新建角色，设置图像、点击与闲置状态，编辑台词，配置基础部件和声音，并分别导出角色包、部件包和台词。

首版在编辑器内提供交互预览，作者可以触发点击动画并查看气泡、试听配音。

作者用独立的可编辑项目保存草稿和素材，可以重新打开项目继续编辑，并从同一项目导出不同版本的 `.cvclk`。

编辑器可以用目录在本地持久化项目及素材。交换格式必须以文件为单位，项目目录本身不可作为交换格式。

首版作者之间通过 `.cvclk` 交接草稿。接手者可从角色包建立编辑项目，编辑与再导出仍受角色包中的作者权限约束。

全局打字反应、音频反应、提醒、PNG/GIF 捕获与 OBS 背景色分阶段交付。首版的文件双向兼容要求见 [格式兼容决策](0001-character-distribution-compatibility.md)。
