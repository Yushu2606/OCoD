# 台词文件 `.txt` / `.csv` / `.md`

台词文件是角色点击台词、自言自语台词的交换格式。原作对三种扩展名使用**同一个**文本解析器；`.csv` 和 `.md` 不是真正的 CSV/Markdown 解析，扩展名只影响文件选择对话框的过滤。

## 1. 文件编码与大小

| 项目 | 规则 |
| --- | --- |
| 大小上限 | 2,097,152 字节（2 MiB） |
| 编码 | UTF-8；可带 BOM |
| 编码回退 | 若 UTF-8 解码结果包含 U+FFFD，原作尝试按 EUC-KR 重新解码 |
| 换行 | `CRLF`、`CR`、`LF` 均可 |
| 导出编码 | UTF-8 **带 BOM** |
| 导出换行 | `CRLF` |

读取方**应当**先去掉开头 BOM，再按 `\r\n|\r|\n` 分行。写入方**必须**写 BOM 与 CRLF，才能与原作逐字节一致。

## 2. 行语法

逐行处理，先对整行做 `trim()`；空行忽略。

### 2.1 区块标题

| 区块 | 匹配（不区分大小写） |
| --- | --- |
| 点击台词 | `[누를 때]`、`[누를때]`、`[클릭]`、`[lines]`，允许 `]` 前有额外文字 |
| 自言自语 | `[혼잣말]`、`[혼자말]`、`[idle]`，允许 `]` 前有额外文字 |

精确正则：

```
点击: /^\s*\[\s*(누를\s*때|누를때|클릭|lines)[^\]]*\]\s*$/i
自语: /^\s*\[\s*(혼잣말|혼자말|idle)[^\]]*\]\s*$/i
```

- 标题行本身不产生台词。
- 见到任一标题后，文件进入“分段模式”；之后的行归入最近一次标题的区块，直到下一个标题。
- 没有任何标题的文件是“无分段文件”；所有行归入导入时当前编辑的台词页（通常是点击台词）。
- 未知标题（例如 `[foo]`）不是标题，按普通台词行处理。

### 2.2 注释

- 以 `#` 开头的行：忽略。
- 以 `//` 开头的行：忽略。
- 注释只在行首（trim 后）生效；行中间的 `#` 或 `//` 属于台词文本。

### 2.3 换行转义

行内的字面量 `\n`（反斜杠 + 小写 n）替换为真正的换行符。该替换在识别样式前缀之前进行。

- 没有其他转义序列；`\\n` 不会被特殊处理。
- 导出时，台词中的每个换行符都转回字面量 `\n`。
- 因此台词无法表达“字面量反斜杠 + n”；这是原作的已知限制。

### 2.4 样式前缀

行的开头可以写：

```
{样式名} 台词正文
```

规则：

- `{...}` 内容为 1–20 个字符，且不能包含 `{`、`}`、换行。
- `{` 与 `}` 必须紧邻行首（trim 后）；`{` 前不能有空格。
- `}` 后至少有一个非空字符，否则整行按普通台词处理。
- 若 `{...}` 内容是 `메모`、`memo`、`メモ`、`備註`（不区分大小写）之一，则不视为样式；整行按普通台词保留，包括花括号。
- 若样式名能在目标角色的样式表中解析，则：
  - 台词正文 = `}` 后的文本（trim）。
  - 该行的样式 ID 写入 `lineStyles`。
- 若样式名无法解析，则整行（包括 `{样式名}`）按普通台词导入，样式为空。
- 样式名不能跨行，不能嵌套。

### 2.5 行的数据结构

解析器对每行产生：

```
{
  raw:   原始行（trim 后、\n 替换后，含可能的 {样式} 前缀）,
  text:  实际台词（若样式解析成功则去掉前缀，否则等于 raw）,
  style: 样式名（未解析或普通行为空字符串）
}
```

导入器再把解析结果写入：

- 点击区块 → `lines`
- 自语区块 → `idleLines`
- 无分段 → 当前台词页对应的键（通常是 `lines`）

## 3. 样式名解析

内置样式的内部名与本地化显示名：

| 内部名（韩文） | 简体中文 | English | 日本語 |
| --- | --- | --- | --- |
| `외침` | 大喊 | Shout | 叫び |
| `혼잣말` | 自言自語 | Mutter | ひとりごと |
| `회상` | 回憶 | Flashback | 回想 |

自定义样式使用作者定义的名字，**不会**被翻译。

解析顺序（原作）：

1. 先比较样式的内部名（内置样式为韩文名）。
2. 再比较当前界面语言下的显示名。

因此：

- `{외침}` 在四种界面语言下都能解析。
- `{大喊}` 只在简体中文界面下解析；在英文界面下会变成字面量文本。
- 原作导出台词文件时按**当前界面语言**写样式名；跨语言交换样式前缀可能失效。

OCoD **应当**在导入时同时匹配内部名和四种语言的显示名，作为对原作的兼容性超集；导出时**应当**按当前界面语言写显示名，以保持与原作文件一致。若实现方只做与原作相同的行为，必须记录跨语言样式前缀失效的限制。

## 4. 导出格式

原作导出的 `.txt` 固定为：

```
# BUG Clicker 대사 파일 · <角色名>
# 한 줄에 대사 하나. # 로 시작하는 줄은 메모입니다. 대사 안에서 줄을 바꾸려면 \n 을 쓰세요.
# 줄 앞에 {스타일 이름} 을 쓰면 그 말풍선 스타일로 나옵니다. 예) {외침} 잠깐만!

[누를 때]
<点击台词 1>
<点击台词 2>

[혼잣말]
<自语台词 1>
<自语台词 2>

```

细节：

- 三个 `#` 注释行是固定文案（韩文），不随界面语言变化；角色名追加在第一行 ` · ` 后。
- 每行台词前若有有效样式，写 `{显示名} `；否则不写前缀。
- 台词中的换行写成字面量 `\n`。
- 空台词不写。
- 文件以 BOM 开头，行间与文件末尾使用 CRLF；最后两个区块之间有一个空行，文件以 CRLF 结束。
- 只导出 `lines` 与 `idleLines`；八个特殊提醒台词不进入台词文件。
- 特殊提醒台词只能在角色包中交换。

## 5. `.csv` 与 `.md`

- 导入对话框接受 `.txt`、`.csv`、`.md`；拖放也接受这三种扩展名。
- 解析器不识别 CSV 的逗号、引号、列，也不识别 Markdown 的标题、列表、强调。
- 因此 `.csv` 中的 `a,b,c` 是一整行台词；`.md` 中的 `# 标题` 会被当作注释忽略（因为以 `#` 开头），`- 列表` 是普通台词。
- 导出永远只写 `.txt`。

实现方**必须**按文本解析，不得按扩展名切换 CSV/Markdown 解析器，否则与原作不兼容。

## 6. 导入合并行为

原作在台词编辑页导入时提供：

- **追加**：文件内容追加到现有台词后。
- **整体替换**：用文件内容替换现有台词。

同时：

- 追加时保留现有 `lineStyles` 与 `lineSounds`，新行样式/声音按解析结果追加。
- 替换时清空对应台词键的样式与声音，再写入新行。
- 若文件有分段，`lines` 与 `idleLines` 分别处理；若无分段，只写入当前页对应的键。
- 若分段文件中存在无区块行（出现在第一个标题之前），这些行被追加到 `lines` 开头。
- 导入后若 `lines` 与 `idleLines` 都为空，提示“没有可导入的台词”。

这些是 UI 行为；交换契约只要求解析结果正确。

## 7. 错误与边界

| 条件 | 行为 |
| --- | --- |
| 文件 > 2 MiB | 拒绝 |
| 无法读取 | 拒绝并提示 |
| 无有效台词 | 提示没有可导入的台词 |
| 样式名未知 | 整行按普通台词导入 |
| `{메모}` 等备忘词 | 不当作样式，整行保留 |
| 行首 `#` / `//` | 注释，忽略 |
| 未知区块标题 | 普通台词 |
| 只有 BOM/空行 | 无有效台词 |
| 台词含字面量 `\n` | 变成真换行（无法转义） |

## 8. 示例

### 8.1 带分段与样式

```
# 这是注释
// 这也是注释

[누를 때]
你好。
{외침} 不要戳我！
第一行\n第二行

[혼잣말]
（发呆）……
{unknown} 这一行会连花括号一起保留
```

解析结果：

- `lines`: `["你好。", "不要戳我！", "第一行\n第二行"]`
- `lines` 样式: `["", "p_shout", ""]`
- `idleLines`: `["（发呆）……", "{unknown} 这一行会连花括号一起保留"]`
- `idleLines` 样式: `["", ""]`

### 8.2 无分段

```
第一句
第二句
第三句
```

从点击台词页导入时，三句都进入 `lines`；从自语页导入时都进入 `idleLines`。

### 8.3 `.csv` 不是 CSV

```
第一列,第二列,第三列
```

导入为一条台词 `第一列,第二列,第三列`，不是三列。
